Core Engine Interface

DataStream<T>::Filter STK-01
Evaluates inline boolean predicates with move semantics, zero dynamic allocation.
BoundedChannel<T>::Write STK-02
Executes atomic ring buffer insertion governed by DropOldest or Block policies.
TumblingWindow<T>::Aggregate STK-03
Collects non-overlapping discrete time slices and computes min, max, and rolling average.
BackpressureStrategy::DropOldest STK-04
Evicts stale telemetry heads when ring buffer reaches capacity, preserving real-time state.
Subject<T>::Broadcast STK-05
Multicasts sensor observations to registered sinks without intermediate heap copying.
AlertDashboardSink::OnNext STK-06
Triggers threshold alarms when windowed metrics exceed critical limits.
